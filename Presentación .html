Información sobre el data set

  • Este data set contiene información sobre las ventas de una farmacia en el período septiembre 2025 a septiembre 2026.
  • Origen del data set: nuestro compañero Francisco nos proporcionó un data set de la farmacia donde trabaja.
  • Cuenta con una dimensión total de 42.000 registros de operaciones y transacciones.
  • Se compone de 33 campos que detallan variables comerciales, temporales y de precios del sector.
  • Contiene información de fecha, precio neto, troquel, nombre del laboratorio, entre otras variables.
